Sistem Kasir Sederhana (PHP) - Versi 2
=====================================

Isi Paket File:
1. index.php  -> Halaman utama kasir (Daftar barang & keranjang)
2. struk.php  -> Halaman pencetakan struk belanja (Alamat: Ds.Pejok , Kec.Kepohbaru, Bojonegoro)

Cara Penggunaan:
1. Ekstrak file ZIP ini ke dalam folder web server lokal Anda (contoh: htdocs/kasir untuk XAMPP).
2. Jalankan Apache / PHP server.
3. Buka browser dan kunjungi: http://localhost/kasir/index.php
